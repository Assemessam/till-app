# Screenshot checklist

No current screenshots are committed yet. The previous Android captures were removed because they showed the retired static catalogue and unpaid-only order page.

After starting the seeded Development environment, capture the current UI without personal data and save approved PNGs under `docs/images/` using these names:

1. `dashboard.png` — dashboard metrics and recent orders.
2. `pos-new-order.png` — category filter, products, cart quantities, and total preview.
3. `catalog.png` — category/product management with an active product.
4. `orders-history.png` — status/search/date filtering and an order action.
5. `maui-pos.png` — the shared POS experience on an Android emulator/device.

Review screenshots after capture for credentials, local file paths, personal data, and stale UI before linking them from the root README.
